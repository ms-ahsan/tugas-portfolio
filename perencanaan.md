# Perencanaan Website Portfolio

| Pertanyaan                           | Jawaban                                                                       |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| Untuk siapa website ini?             | Recruiter, dosen, dan calon klien freelance.                                  |
| Apa tujuan utamanya?                 | Memperkenalkan Pratama serta menunjukkan proyek web dan pengalaman belajar.   |
| Tindakan yang diharapkan pengunjung? | Melihat proyek, mengunduh CV, dan menghubungi melalui email.                  |
| Konten apa yang tersedia?            | Bio, daftar keterampilan, data proyek, riwayat pendidikan, dan kontak contoh. |
| Apa yang membedakan saya?            | Fokus pada HTML semantik, aksesibilitas, dan proyek pembelajaran yang nyata.  |

> Catatan: nama, alamat email, tautan sosial, dan CV pada proyek ini masih contoh dan perlu diganti sebelum dipublikasikan.
